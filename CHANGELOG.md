## 1.5.3

### Radial menu
- The radial menu is now an interactive overlay instead of a full screen — the world keeps rendering behind it and the HUD stays visible.
- New `Activate on release` option: a shortcut always fires on press, and additionally fires on mouse release when enabled.
- Right click goes back one level, or closes the menu when already at the root.

### Fixes
- The menu now closes properly when another screen is opened.
- The centre button no longer double-triggers when release activation is enabled.
